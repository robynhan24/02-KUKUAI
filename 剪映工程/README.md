# 剪映工程

`库库AI_剪映草稿/` 是剪映专业版草稿，和网页预览是同一条时间线（第 1–5 段，整片约 147 秒）。

**精细分层**（阿亮 10-20）：每个素材都是剪映里独立的片段，像正常剪辑那样可以单独改、单独替换——口播是口播、录屏是录屏、小圆窗是口播加圆形蒙版、标注是透明图片。只有导航卡、logo、示意动画这类网页里做的动画，是渲染好的一段视频。

## 在剪映里打开

1. `git pull` 拉最新代码。
2. 运行 `python 剪映工程/装到剪映.py`（只要装了 Python 3）。它会把草稿拷进本机剪映的草稿文件夹，并把素材路径改成本机路径。
   剪映草稿文件夹不在默认位置时，在剪映「全局设置 → 草稿位置」查到路径，运行 `python 剪映工程/装到剪映.py "那个路径"`。
3. 重启剪映（或进出一次任意草稿），首页打开「库库AI_剪映草稿」。

不想运行脚本，也可以把 `库库AI_剪映草稿` 整个文件夹手动拷进剪映草稿文件夹；如果打开后提示素材丢失，点「链接媒体」，选 `素材` 文件夹里的任意一个文件，其余会一起找回。

## 轨道（从下到上）

| 轨道 | 内容 | 在剪映里怎么改 |
| --- | --- | --- |
| 主画面 | 真人全屏（口播视频，带推近的缩放/位置关键帧）；录屏场景的背景图（网格 + 光晕）；导航卡、logo、示意动画（渲染好的视频） | 真人：直接调缩放、位置；背景：换图片 |
| 手机虚化底 | 手机录屏下面那层：同一画面放大、虚化 | 不透明度、换素材 |
| 手机压暗 | 压暗 + 紫色柔光（透明 PNG） | 删掉或调不透明度 |
| 录屏 | 录屏 / 截图原素材，圆角矩形蒙版；从右侧滑入的位置关键帧 | 替换素材、改蒙版圆角、改位置大小、调变速 |
| 虚化压暗 | 放大重点时垫在下面的虚化压暗版录屏（不透明度关键帧淡入） | 删掉就不虚化 |
| 放大 | 同一录屏再放一份，矩形蒙版只露出重点区域，缩放 + 位置关键帧从原位置放大到画面中间 | 调蒙版范围（选别的重点）、改关键帧 |
| 标注（2、3…） | 放大框的橙色描边、涂黄、虚线框，每个一段透明 PNG；结尾黑场 | 挪时间、删掉 |
| 手机外框 | 手机机身外框（透明 PNG） | 换外框图 |
| 小圆窗 | 口播视频 + **圆形蒙版**，左下角 | 直接在剪映「蒙版」里调圆的大小和位置，或调片段的缩放、位置 |
| 小圆窗边框 | 紫色圆环（透明 PNG） | 小圆窗挪了，圆环跟着挪 |
| 字幕 | 每句一段文字（白字黑底） | 直接改字、改样式 |
| 人声 | 口播，按剪辑表切好（长停顿已剪短） | 微调切点 |
| 配乐1、2 | 每段一首，带音量关键帧：说话时压低，停顿和章节卡处抬起 | 换曲、调音量 |
| 音效1… | 转场、重击、弹出、闪光等 | 删、挪、换 |

## 需要注意

- **蒙版位置**：小圆窗和「放大」层的蒙版位置是按剪映「上为正」的坐标写的。第一次打开如果发现圆里的人或放大的区域偏了，说明剪映版本坐标方向不同，告诉 Claude，或者直接在蒙版里拖回去。
- 网页里涂黄是「从左往右扫过去」的动画，剪映里改成了淡入的透明图片。
- 动画片段（主画面里的 `动画_xx.mp4`）是网页里渲染的整段画面，里面的字和动画要改，告诉 Claude 改网页时间线再更新工程。
- 字幕字号、背景是按 1080p 设的近似值，第一次打开看一下大小。
- 我这边没有剪映，草稿按开源库 pyJianYingDraft 的格式生成（它标注支持剪映 5.9 和新版）。打不开或效果不对，告诉 Claude 你的剪映版本号。

## 怎么更新（给 Claude）

```bash
python3 剪辑工程/jianying.py      # 按网页时间线重新生成整个剪映草稿（动画片段有缓存，没改的不重渲）
```
