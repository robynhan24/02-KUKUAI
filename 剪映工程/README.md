# 剪映工程

`库库AI_剪映草稿/` 是剪映专业版草稿，和网页预览是同一条时间线。每剪完一段，这个草稿会整体更新（同一个工程，新段落接在后面）。

## 在剪映里打开

1. `git pull` 拉最新代码。
2. 运行 `python 剪映工程/装到剪映.py`（只要装了 Python 3）。它会把草稿拷进本机剪映的草稿文件夹，并把素材路径改成本机路径。
   剪映草稿文件夹不在默认位置时，在剪映「全局设置 → 草稿位置」查到路径，运行 `python 剪映工程/装到剪映.py "那个路径"`。
3. 重启剪映（或进出一次任意草稿），首页打开「库库AI_剪映草稿」。

不想运行脚本，也可以把 `库库AI_剪映草稿` 整个文件夹手动拷进剪映草稿文件夹；如果打开后提示素材丢失，点「链接媒体」，选 `素材` 文件夹里的任意一个文件，其余会一起找回。

## 轨道（从下到上）

| 轨道 | 内容 | 能改什么 |
| --- | --- | --- |
| 画面 | 每个镜头一段，网页里合成好的画面（录屏放大、导航卡、动画都在里面），**不带字幕** | 剪短、换顺序、加转场、调色、替换 |
| 字幕 | 每句一段文字（白字黑底，屏幕下方） | 直接改字、改字体样式 |
| 人声 | 口播，按剪辑表切好（停顿已剪短） | 微调切点、降噪 |
| 配乐 | 每段一首，带音量关键帧：说话时压低，停顿和章节卡处抬起 | 换曲、调音量 |
| 音效1… | 转场、重击、弹出、闪光等，重叠的分到不同轨道 | 删、挪、换 |

## 注意

- 画面轨里的特效（局部放大、虚化、涂黄、动画）是在网页里做好再导出的，剪映里不能单独改某个涂黄框；要改这些，告诉 Claude 改网页时间线，再更新工程。
- 字幕字号、背景是按 1080p 设的近似值，第一次打开看一下大小合不合适。
- 草稿按剪映新版（7 以上）和 5.9 都能读的格式生成；如果你的剪映版本打不开，告诉 Claude 版本号。
- 素材：`素材/画面_第N段.mp4`（每段画面）、`人声.mp3`、`配乐*.mp3`、`音效_*.mp3`。

## 怎么更新（给 Claude）

```bash
python3 剪辑工程/render.py 4      # 渲染新段落（或改过的段落）的画面
python3 剪辑工程/jianying.py      # 按网页时间线重新生成整个剪映草稿
```
