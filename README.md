## 怎么预览

网页实时播放，不用先渲染：仓库根目录起一个本地服务，再用浏览器打开 `index.html`。

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

点画面或按空格播放；← → 逐帧，Shift+← → 跳 1 秒。右下「导出」会实时录一遍，下载成片（Chrome 出 webm，Safari 出 mp4）。

## 阿亮的修改意见（后面每一段都要遵守）

**最新（10-20 第三版，和下面旧条目冲突时以这里为准）**

- **录屏全屏**：录屏素材本来就是 16:9，凡是演示操作都铺满全屏（`KDraw.recFull`），不再缩成窗口、不再把局部弹出来放大。讲重点时用**关键帧镜头推拉**（`cam: [[时间, 区域]...]`，推近 / 平移 / 拉远）到那一块，再配**框选**（橙红描边）或**马克笔**涂黄。时间线里统一用 `fullScene()`。
- **节奏**：同一段连贯录屏尽量连着放，操作和口播对上；太长就截重点步骤或稍微加速（1–1.3 倍），宁可停在关键一帧推近，也不要来回快切。换录屏素材用过渡（从网格底淡入 + 轻推），同一录屏里跳一段用短暂淡出淡入（`cuts`）。不再白闪。
- **开头**：直接全屏 3D 交互课件高光，镜头推到被拖的曲面、再移到旋转切平面。
- **小圆窗**：位置固定在左下角，不做弹出动画。
- **字幕**：得意黑（SmileySans-Oblique），白字深色描边，不加黑底。
- **背景**：所有黑底换成黑色网格底，白线很淡（`KDraw.bg`）。
- **网页端截图**：「网页端和桌面端」画面左边的浏览器用阿亮给的网页版首页（`assets/k_web.png`）。
- **剪映工程不再更新**，以后也不用提供剪映相关内容。

- **（第四版）放大要适中**：镜头推近时以「看清又不撑满」为准，比如 3D 课件同时露出 01、02 两个模块（`M12`）。
- **（第四版）定格**：录屏定格时视频暂停在准确的那一帧（`E.video(名, 秒, 0)`），不能上下抖；快放用播放速度（`E.video(名, 秒, 1.3)`），不靠反复跳帧追。
- **（第四版）软切时镜头直接到位**：同一录屏跳一段时，镜头在淡出淡入的那一下直接到新位置（`cam` 第三项写 0），不要先拉远再推近。
- **（第四版）logo 不单独开画面**：直接出现在真人画面右边空白处（`logoOn`）；停顿里真人慢放，不露没声音的口型。
- **（第四版）一组内容用一个框**：参考文献之类一整组内容，定格后用一个选框框住，不逐条涂黄。

**旧条目**


- **10-20 录屏全显**：所有录屏、截图都整屏显示，窗口约 1680×945（画面大部分），不再只裁一小条。讲到重点时，把那一块从原位置放大到画面中间（橙色描边），背景整屏录屏同时虚化、压暗；涂黄和虚线框画在放大的那块上。引擎里是 `KDraw.rec()`，时间线里用 `recScene()`。整屏里的国内模型名、快捷键提示用白块盖掉（`prep_assets.sh`）。
- **10-20 人物居中**：左下角小圆窗里人物脸居中（按 `剪辑工程/anchor_track.js` 里的头部轨迹裁，换口播后跑 `track_anchor.py`）；真人全屏/近景画面人物水平居中，头顶留白一致（全景约 12%，近景约 8%），近景放大到约 1.2 倍为止。
- **10-20 剪映工程**：每段剪完都要同步更新 `剪映工程/库库AI_剪映草稿`（同一个工程，新段落接在后面），见 `剪映工程/README.md`。
- **10-20 少用重复动效，多用原录屏**：阿亮的录屏是处理好的，能整段播放就整段播放，按口播截取对应的那一段，用快进/分段变速对齐口播；不要每句都放大框选（第 4 段 1:47 以后已改成这样）。不需要单独放大滑块这类小控件。

- **10-20 剪映工程要精细分层**：每个素材都能在剪映里独立调整/替换（口播圆形蒙版、录屏蒙版、放大层、标注 PNG），不是整段渲染好的画面。
- **10-20 小圆窗**：人物水平居中，头放在圆的上部，多露出上半身（裁 310×310，头顶上方留 8%）。
