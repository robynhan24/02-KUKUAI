## 怎么预览

网页实时播放，不用先渲染：仓库根目录起一个本地服务，再用浏览器打开 `index.html`。

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

点画面或按空格播放；← → 逐帧，Shift+← → 跳 1 秒。右下「导出」会实时录一遍，下载成片（Chrome 出 webm，Safari 出 mp4）。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 预览页 |
| `网页引擎/engine.js` | 通用轻量引擎（纯 JS + Canvas，无 npm）：素材加载、视频同步、WebAudio 混音、字幕、自查跳帧、导出 |
| `剪辑工程/timeline.js` | 本期时间线：口播剪辑表、字幕、场景、配乐和音效 |
| `剪辑工程/prep_assets.sh` | 把原素材转成网页用的小文件（mp4 + webm 两份） |
| `剪辑工程/make_fonts.py` | 从字体里抽出用到的字，做成小网页字体 |
| `剪辑工程/check.py` | Chromium 打开网页，跳到关键时间点截图拼联系表 |
| `剪辑工程/assets/` | 生成好的网页素材 |
